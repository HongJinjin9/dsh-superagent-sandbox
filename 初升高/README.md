## 二、一页速览（2026 年口径）

| 项目 | 内容 |
|---|---|
| 适用政策 | 2026 年起中考以 630 分计（深教规〔2024〕3 号，适用至 2029 届；以当年正式发文为准） |
| 科目与分值 | 语文 120、数学 100、英语 100（听说 25）、物理与化学合卷 140（含实验操作 20）、历史 70、道法（开卷）50、体育 50（现场 36 + 过程性 14） |
| 三条升学路径 | ① 名额分配（校内竞争，比统招低约 20 分）② 第一批统招 ③ 二类自主招生（艺术/体育，中考 60% + 专项 40%） |
| 关键红线 | 名额分配要求初中三年完整学籍、不得转学；生地会考缺考不能投档；体育过程性评价从初一开始计分 |
| 舞蹈的真相 | 深圳中考**没有任何艺术类加分**；舞蹈走的是「二类自主招生」，录取后锁定、不得转录，未录取不影响后续批次 |
| 中本贯通 | 属于**统一招生第一批**，与普高共用 16 个志愿（12 普高 + 4 中职）；**排在普高之后才是兜底**，排在前面被录则普高志愿全部作废 |

更完整的结论、数据与推断过程见主文档。

## 三、脱敏说明（重要）

本档案由包含个人信息的原始会话整理而来，**已针对公开分享做脱敏**：

**已删除或泛化**
- 未成年人姓名、证件号码、出生日期、照片、聊天记录截图、参赛作品名与具体赛事名；
- 就读学校名称与班级（全文统一以「本校」指代，区级位置保留，仅用于通勤与本地学校建议）；
- 个人考试分数与年级/班级位次（保留「约处中游（百分位约 33%）」等泛化描述与换算方法）；
- 个人联系方式、家庭住址、本地文件路径、账号与数据库连接信息。

**未收录的原始素材及原因**
- 原始会话 JSONL（含系统提示词、本地路径与全部对话内容）：体量大且含过程性隐私信息；
- 44 张图片：包括舞蹈获奖/社会实践电子证书（含姓名、证件号）、家长会现场展板照片、聊天与成绩查询截图等；
  其中**官方分数线表格已逐条转录为上面的 CSV**，无需依赖图片；
- VCP 智能体「星禾」的人设文件：属于另一项任务，且内含个人学情档案。

**保持原样**
- 政策文件原文引用、各高中录取线与名额分配数据、官方来源链接——均为公开信息。

> 本档案中的「本校」指原规划所指的就读初中。若需完整原始数据，请查阅本地私密原件。

## 五、使用与更新

- **每年 3 月中旬**：查看深圳市教育局官网当年的中考招生工作通知，确认政策与日程是否有变；
- **每年 5 月**：下载当年的《考生报考指导手册》，更新名额分配控制线与本校名额；
- **每年 7 月**：更新各高中录取分数线、中本贯通专业点与录取线；
- **初二下（2028.6）**：生地会考；**初三下（2029.5）**：志愿填报。
- 2029 届考生适用 2026 年落地的 630 分方案（深教规〔2024〕3 号有效期至 2029 年 4 月），**政策存在调整可能，一切以当年正式文件为准**。中本贯通 2025 年首办、2026 年扩容，**不宜线性外推**。
